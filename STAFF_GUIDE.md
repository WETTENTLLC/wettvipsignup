## Troubleshooting

### "QR Code Won't Scan"
**Solution:**
1. Make sure customer's screen brightness is high
2. Try using your phone's built-in Camera app instead
3. Hold phone steady, not too close (4-6 inches away)
4. Good lighting helps!

### "I Don't See the Pass Details"
**Solution:**
1. Check your internet connection
2. Reload the page (press F5 or swipe down to refresh)
3. Copy the pass code and text it to WETT support

### "It Says the Pass is Invalid"
**Solution:**
1. This pass is NOT a real WETT pass
2. Do not let customer in
3. Contact WETT support with the code they tried to use

### "It Says Already Used"
**Solution:**
1. Customer already used this pass earlier
2. They need to get a NEW pass
3. Tell them to tap an NFC tag to get a new pass code
4. New QR code will work the second time

### "No Internet Connection"
**Solution:**
1. This is a problem - we need internet to verify
2. Connect to your WiFi
3. If still no connection, contact WETT support
